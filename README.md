# サ道 サウナマップ

**https://mifune39428.github.io/sado-sauna-map/**

ドラマ『サ道』シリーズ（2019年のシーズン1から2026年の5日連続放送まで）に出てきたサウナ施設 **55 か所** を
地図にまとめたものです。スマホのブラウザでそのまま開けます。
ピンをタップすると、**男性専用か女性も入れるか・料金の目安・定休日・営業時間**と、
どのシリーズの何話に出たかが出ます。

## 使い方

- **ピンの色** … 最初に登場したシリーズごとの色分け
- **点線のうすいピン** … 回想・参考映像・外観だけで出てきた施設
- **斜線入りのグレーのピン** … 閉館した施設・一般利用できない施設
- **絞り込み** … 「だれが入れるか」「登場のしかた」「シリーズ」での絞り込みと、施設名・地名での検索
- **📍** … 現在地を表示。近い順のリストから施設に飛べます

iPhone は Safari の共有ボタンから**「ホーム画面に追加」**にすると、
上下のバーが消えて全画面で使えます（初回だけ画面上部に案内が出ます）。

## 出典と注意

- **どの回にどの施設が出たか** … [Wikipedia「サ道」](https://ja.wikipedia.org/wiki/%E3%82%B5%E9%81%93)の放送日程表。
  各話のメイン施設だけでなく、回想シーンや参考映像として映った施設も載っているので、それに合わせています。
  シーズン1の各話サブタイトルは[テレビ東京の公式ページ](https://www.tv-tokyo.co.jp/sa_una37/story/)で確認しました。
- **施設の情報**（男女別・料金・定休日・営業時間・住所・座標）… [サウナイキタイ](https://sauna-ikitai.com/)。
  海浜あみだ湯・改良湯・ジェクサー新宿・高輪SAUNAS は公式サイトの記載を優先しています
  （改良湯はサウナイキタイが「定休日なし」でしたが、公式は土曜定休でした）。

**料金・定休日・営業時間は変わります。お出かけ前に必ず公式情報でご確認ください。**
ポップアップの「サウナイキタイ」「公式サイト」から元の情報に飛べます。

### 分かっていないこと

- サ道2021 の参考映像に出てくる**白山湯**は、高辻店と六条店のどちらかが特定できていません。
  地図には高辻店を置いています。
- 2023年冬SPの参考映像として Wikipedia が挙げている「ゴールデンスパニューオーツカ」と、
  2025年冬SPの「毎日サウナ」は、施設や支店を特定できなかったので入れていません。
- 2022年冬SPの「ナカタサウナ」（ナカタが自分で建てたもの）、2023年冬SPの「サウナカー」、
  2019年末SPの「吹上露天の湯」（サウナはない露天風呂）は、施設ではないので入れていません。
- サ道2026 第二話には施設が出てきません（Wikipedia の放送日程表にも記載がない）。
- 第四話の**日暮里 斉藤湯はサウナが無い**ため、サウナイキタイに載っていません。
  座標は国土地理院のジオコーディング、その他は東京都浴場組合の記載によります。
  公式サイト（saito-yu.com）はドメインが失効していたので付けていません。

## 構成

```
index.html      地図本体（HTML/CSS/JS 一体）
saunas.json     施設データ
vendor/         Leaflet 1.9.4 + Leaflet.markercluster 1.5.3（CDN 不要）
tools/          saunas.json を作り直すためのスクリプト
```

### データを作り直す

`tools/` で以下の順に実行します。

```bash
python3 fetch_from_search.py 高輪SAUNAS 改良湯   # 施設名 → ikitai.json に追記
python3 build.py                                 # 各話データと突き合わせて ../saunas.json を出力
```

登場回・料金の要約・施設メモは `build.py` の `F` に手で書いてあります。
新しいシリーズが放送されたら、Wikipedia の放送日程表を見て `SERIES` `EP_TITLE` `F` に足してください。
サウナイキタイに無い施設（閉館・非公開・サウナ無し）は `MANUAL` に座標を直接書きます。
サウナイキタイの記載が公式と食い違うときは `HOLIDAY_OVERRIDE` / `HOURS_OVERRIDE` に書きます。

**施設詳細ページ（`/saunas/<id>`）は AWS WAF の CAPTCHA が出るようになり、自動取得できません。**
`robots.txt` では許可されていますが、実際には 405 と CAPTCHA が返ります。**CAPTCHAは回避しません。**
代わりに検索ページ（`/search?keyword=`）に埋まっている地図表示用の JSON（`window.__MAP_DATA`）を
使っています。座標・住所・男女別の可否・定休日・営業時間はここに入っていますが、
**公式サイトのURLと電話番号だけは入っていない**ので、`fetch_from_search.py` の `OFFICIAL` に手で書きます。
詳細ページを見に行っていた古い `search_ids.py` / `fetch_details.py` は、動かないので消しました
（必要なら `git log` から取り出せます）。

地名で検索すると無関係な施設が先頭に来る（「日暮里」→「スポーツクラブNAS 西日暮里」）ので、
`fetch_from_search.py` は施設名の頭から一致するものだけを採り、曖昧なら飛ばします。
名指ししたいときは `施設名=ID` と書きます。

`.nojekyll` は GitHub Pages に必要です。無いと Jekyll が `vendor/` を除外して Leaflet が読めなくなります。

地図タイルは [OpenStreetMap](https://www.openstreetmap.org/copyright) を利用しています。
